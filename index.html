    Built for developers

    Everything you need to inspect, learn from, and reuse a website's front end.

    Full source extraction

    HTML, CSS and JavaScript are separated automatically, formatted, and ready to read.

    Syntax highlighting

    A monochrome highlighting theme that keeps structure legible without a splash of color.

    Render the extracted page in a sandboxed frame, across desktop, tablet and mobile widths — the closest thing to a screenshot, except it's live and interactive.

    Fingerprints frameworks and libraries in the page — React, Vue, Next.js, Tailwind, WordPress and more — from the code it actually ships.
