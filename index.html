    03 — UNDER THE HOOD

    What a scan actually does

    Seven steps run the moment you paste a URL — no login, no server round-trip you can't see.

    01 Split source The DOM is walked and separated into HTML, CSS and JavaScript, formatted and ready to read.
    02 Highlight A monochrome syntax theme keeps structure legible without a splash of color.
    03 Render The page loads in a sandboxed frame at desktop, tablet and mobile widths — live, not a screenshot.
    04 Fingerprint Frameworks and libraries are identified from the code the page actually ships — React, Vue, Next.js, Tailwind, WordPress and more.
    05 Check SEO Title length, headings, alt coverage, canonical and Open Graph tags — scored, with every meta tag laid out in a table.
    06 Read headers Shows exactly which response headers your browser can see, and is explicit about the ones it can't — a CORS limit, not a guess.
    07 Package for export Every image, font and script referenced is listed with a direct link; the whole extraction downloads as one .zip.
